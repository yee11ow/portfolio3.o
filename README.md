# Matvii — portfolio v3

Одностраничное портфолио с нишевым позиционированием:
**сайты для B2B-фирм профессиональных услуг** — advokatbyråer (юрфирмы),
revisionsbyråer (аудит/бухгалтерия) и консалтинг. Двуязычный **EN / SV**.

Чистая статика: `index.html` + `styles.css` + `script.js` + `assets/`.
Никакой сборки и зависимостей.

---

## Позиционирование

Ключевая мысль: **«Ваш сайт — это первая встреча с клиентом»**.
Для юристов и аудиторов конверсия — не «запись», а **доверие и
квалифицированное обращение**. Отсюда вся структура:

| Блок | Задача |
|------|--------|
| Hero | За 5 секунд сказать, кому и что ты делаешь |
| From visitor to qualified enquiry | Назвать проблему: понять → доверять → связаться |
| Work | Два **живых** концепта, кликабельных прямо с сайта |
| About | Почему тебе можно доверить фирму такого типа |
| How I work | 3 шага + что входит в работу (снимает риск) |
| Final CTA | Бесплатные 15 минут, low-commitment |

## Запуск локально

Сайт лежит в `public/` — запускать нужно **оттуда**, иначе относительные пути
не найдут `assets/`:

```bash
cd public && python3 -m http.server 8000
# открой http://localhost:8000
```

## Деплой

Весь сайт — это содержимое `public/`. Сборки нет, зависимостей нет.

### Cloudflare Pages (текущий хостинг)

| Настройка | Значение |
|-----------|----------|
| Build command | *пусто* |
| Build output directory | `public` |
| Root directory | `/` |

> Первый деплой падал с `Error: Output directory "public" not found` — Pages
> искал папку `public`, а файлы лежали в корне репозитория. Поэтому сайт
> переехал в `public/`: так совпадает с уже настроенным в дашборде, и корень
> репозитория остаётся под README и конфиги.
>
> Альтернатива, если захочешь плоскую структуру обратно: вернуть файлы в корень
> и поменять **Build output directory** на `/`. Что-то одно, не оба сразу.

`public/_headers` Cloudflare Pages читает автоматически — там security-заголовки
и кеширование шрифтов.

**HSTS включён** прямо в `_headers`:
`max-age=31536000; includeSubDomains`. Поддомены с концептами он тоже
покрывает — они и так только по HTTPS на Pages, так что ничего не ломается.
`preload` намеренно **не** ставил: попасть в browser preload list легко, а
выйти из него — месяцы, и для портфолио эта цена того не стоит.

Другие хостинги, если понадобится: Netlify (publish directory — `public`),
Vercel (Framework *Other*, output `public`), GitHub Pages.

## Как устроена двуязычность

- Каждый текст продублирован: `<span lang="en">…</span><span lang="sv">…</span>`.
- CSS показывает только активный язык; переключатель **EN / SV** в шапке.
- Выбор сохраняется в `localStorage`; при первом заходе берётся язык браузера
  (sv → SV, иначе EN).
- Без JavaScript сайт работает и показывает английскую версию.

Правишь текст — правь **обе** версии рядом.

> Нужен третий язык (RU/UA)? Механика уже готова: добавь `<span lang="ru">` рядом,
> кнопку в `.lang` и `ru` в массив `SUPPORTED` в `script.js`.
> В `styles.css` дополни правило `html[lang="…"] [lang="…"] { display: none; }`.

## Дизайн-система

- **Палитра:** графит `#18191b` + слоновая кость `#f7f6f3` + камень `#eeece7`,
  единственный акцент — приглушённая латунь `#8a6a35`.
- **Шрифты:** **Spectral** (Production Type) — заголовки **и вся проза.
  Классические переходные пропорции, но нарисован под экран: резкие засечки,
  крупный x-height, слегка узкий. Inter остаётся только на интерфейсе —
  навигация, кнопки, бейджи, подписи-капсы.

### Шрифты захостены локально

Google Fonts CDN убран полностью. Причина не в скорости: немецкий суд
(LG München, 2022) признал загрузку шрифта с серверов Google нарушением GDPR —
IP посетителя уходит третьей стороне без согласия. Для сайта, который продаёт
себя адвокатским и аудиторским бюро, это тот самый прокол, который заметят
первым.

- `assets/fonts/*.woff2` — Spectral 400/500 и Inter (вариативный), subsets
  `latin` + `latin-ext`.
- `assets/fonts/fonts.css` — локальные `@font-face`.
- `assets/fonts/OFL-*.txt` — тексты лицензий. Оба шрифта под SIL OFL 1.1,
  которая **обязывает** распространять лицензию вместе с файлами.

На диске ~184 КБ, но благодаря `unicode-range` для страницы на EN/SV реально
качается **~80 КБ**: файлы `latin-ext` браузер не тронет, пока на странице не
появится символ из их диапазона.

Проверено в браузере: **0 внешних запросов**, 0 кук.
- Mobile-first, уважает `prefers-reduced-motion`, есть skip-link и focus-стили.

```
README.md              этот файл
public/                ← всё, что уезжает на хостинг
  index.html           главная — разметка и весь контент (EN + SV)
  legal.html           юридическая страница (EN + SV)
  styles.css           палитра, типографика, сетки, адаптив, печать
  script.js            переключатель языка, blur шапки, мобильное меню, reveal
  _headers             CSP и кеширование для Cloudflare Pages
  assets/              SVG-мокапы, портрет, фавикон
  assets/boot.js       ставит язык до отрисовки (отдельный файл ради CSP)
  assets/fonts/        локальные woff2 + fonts.css + лицензии OFL
```

### Про CSP

В `_headers` прописан строгий `Content-Security-Policy`: `default-src 'none'`,
и обратно разрешено только своё же (`'self'`). Это не украшение — юридическая
страница обещает, что открытие сайта ни с кем, кроме этого домена, не
связывается, и CSP заставляет браузер это соблюдать, а не верить на слово.

Побочное следствие: **инлайновые скрипты запрещены**. Поэтому скрипт выбора
языка вынесен в `assets/boot.js`. Если будешь добавлять инлайновый `<script>`
или `style="..."` — он молча не сработает. Либо выноси в файл, либо ослабляй
политику (лучше первое).

## ⚖️ Юридическая часть

`legal.html` — двуязычная страница: кто владелец сайта, что происходит с
данными, куки и лагрование, третьи стороны, права по GDPR, статус концептов,
авторские права и лицензии шрифтов.

**Что уже сделано технически:**

- **0 внешних запросов** — шрифты локальные, нет аналитики, тег-менеджера,
  пиксела и встроенных соцсетей. IP посетителя не уходит никуда.
- **0 кук.**
- `localStorage` пишется **только по клику** на переключатель языка. Раньше
  запись шла при каждой загрузке — то есть на устройство сохранялось нечто без
  всякого действия пользователя, а именно это и регулирует ePrivacy. Хранится
  один ключ `lang` со значением `en`/`sv`: ни идентификатора, ни отправки на
  сервер. Такое «пользователь сам выбрал настройку отображения» относят к
  функциональному хранению, не требующему баннера согласия.
- Дисклеймер по концептам продублирован в футере главной и раскрыт в
  `legal.html#koncept`: фирмы не заказывали и не одобряли работы, названия и
  тексты принадлежат им, и по первой просьбе концепт снимается.
