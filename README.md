# Matvii — portfolio v3

Одностраничное портфолио с нишевым позиционированием:
**сайты для B2B-фирм профессиональных услуг** — advokatbyråer (юрфирмы),
revisionsbyråer (аудит/бухгалтерия) и консалтинг. Двуязычный **EN / SV**.

Чистая статика: `index.html` + `styles.css` + `script.js` + `assets/`.
Никакой сборки и зависимостей.

---

## Позиционирование

Ключевая мысль: **«Ваш сайт — это первая встреча с клиентом»**.
Для юристов и аудиторов конверсия — не «запись», а **доверие и
квалифицированное обращение**. Отсюда вся структура:

| Блок | Задача |
|------|--------|
| Hero | За 5 секунд сказать, кому и что ты делаешь |
| From visitor to qualified enquiry | Назвать проблему: понять → доверять → связаться |
| Work | Два **живых** концепта, кликабельных прямо с сайта |
| About | Почему тебе можно доверить фирму такого типа |
| How I work | 3 шага + что входит в работу (снимает риск) |
| Final CTA | Бесплатные 15 минут, low-commitment |

## Кейсы

Тексты кейсов написаны по **исходникам двух живых концептов** (присланы в виде
HTML), а не по догадкам. Каждая деталь взята из самого концепта:

**FB Revision** — Företagarnas Revisionsbyrå i Uppsala AB, Drottninggatan 4,
с 1975 (корни с 1950-х), 14 сотрудников, 3 авторизованных ревизора,
3 авторизованных консультанта по учёту, SRF konsulterna.
Найденное на боевом сайте и вынесенное в кейс: нет H1, `lang="en-US"` при
шведском контенте, телефон обычным текстом (не нажать), «50 лет» на главной
против «30 лет» на странице услуг, WordPress-штамп «admin 2018-11-29»,
четыре gif-картинки. Концепт несёт свою секцию «Vad som ändras — och varför».

**Nordström Advokater** — Уппсала и Сала, с 1986, 8 юристов, из них
**6 — конкурсные управляющие по назначению Uppsala tingsrätt**,
13 областей права. Ключевое: `user-scalable=0` на боевом сайте блокировал
pinch-zoom (WCAG 1.4.4), и **Konkursportalen** — маршрутизация по ситуации
(требование / зарплата / аренда) сразу к нужному управляющему с номером дела.
Весь концепт `noindex` — чтобы кредитор не подал реальное требование в форму,
которая никуда не ведёт.

> Позиционирование намеренно осторожное: кейсы подписаны как **egeninitierade
> koncept**, и прямо сказано, что фирмы их не заказывали и не одобряли — так же,
> как это сформулировано в дисклеймерах на самих концептах.

Кейсы в коде: `index.html`, секции `<!-- Case 1 — FB Revision -->` и
`<!-- Case 2 — Nordström Advokater -->`.

## Как устроена двуязычность

- Каждый текст продублирован: `<span lang="en">…</span><span lang="sv">…</span>`.
- CSS показывает только активный язык; переключатель **EN / SV** в шапке.
- Выбор сохраняется в `localStorage`; при первом заходе берётся язык браузера
  (sv → SV, иначе EN).
- Без JavaScript сайт работает и показывает английскую версию.

Правишь текст — правь **обе** версии рядом.

> Нужен третий язык (RU/UA)? Механика уже готова: добавь `<span lang="ru">` рядом,
> кнопку в `.lang` и `ru` в массив `SUPPORTED` в `script.js`.
> В `styles.css` дополни правило `html[lang="…"] [lang="…"] { display: none; }`.

## Дизайн-система

- **Палитра:** графит `#18191b` + слоновая кость `#f7f6f3` + камень `#eeece7`,
  единственный акцент — приглушённая латунь `#8a6a35`.
- **Шрифты:** Newsreader (заголовки) + Inter (текст), с системными фолбэками.
- Mobile-first, уважает `prefers-reduced-motion`, есть skip-link и focus-стили.
