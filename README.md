# Matvii — portfolio v3

Бутиковый одностраничный сайт-портфолио с нишевым позиционированием:
**booking-ready сайты для beauty & wellness студий** (ресницы, брови, ногти,
косметология, пилатес, йога). Двуязычный — EN / RU, под диаспору и Норрланд.

Чистая статика: `index.html` + `styles.css` + `script.js` + `assets/`.
Никакой сборки и зависимостей.

---

## Запуск локально

Просто открой `index.html` в браузере. Либо подними локальный сервер
(чтобы корректно работали относительные пути и шрифты):

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Деплой

Залей папку как есть на любой статический хостинг и подключи домен
`matviiakkuratov.com`:

- **Netlify** — перетащи папку в дашборд или подключи репозиторий (build command пустой, publish directory — корень).
- **Vercel** — Import Project → Framework: *Other* → деплой.
- **GitHub Pages** — Settings → Pages → Deploy from branch.

## Как устроена двуязычность

- Каждый текст продублирован двумя `<span lang="en">…</span><span lang="ru">…</span>`.
- CSS показывает только активный язык; переключатель **EN / RU** в шапке.
- Выбор сохраняется в `localStorage`; при первом заходе берётся язык браузера
  (ru → RU, иначе EN).
- Работает и без JavaScript: по умолчанию показывается английская версия.

Чтобы отредактировать текст — правь обе языковые версии рядом в `index.html`.

## Структура

```
index.html      разметка и весь контент (EN + RU)
styles.css      тёплая editorial-палитра, Fraunces + Inter, mobile-first
script.js       переключатель языка, blur навигации, мобильное меню, reveal
assets/         SVG-заглушки (мокапы, before/after, портрет, фавикон)
```

## Разделы

1. **Hero** — нишевый заголовок + мокап телефона + одна кнопка Book a call.
2. **Booking flow** — «запись, а не просто просмотр».
3. **Work** — 2 концепта по схеме *Проблема → Подход → Было/Стало*.
4. **About** — Стокгольм + фэшн/фото-глаз + EN/RU/UA (мост к диаспоре).
5. **How I work** — 3 шага, снимают страх первого заказа.
6. **Final CTA** — бесплатный звонок 15 минут.
7. **Footer** — рабочие ссылки на твоём домене.
