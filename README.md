# matviiakkuratov.com

Портфолио. Ниша: **B2B-фирмы профессиональных услуг** — advokatbyråer,
revisionsbyråer, redovisningsbyråer и консалтинг в Швеции.

Двуязычный: шведский по умолчанию, английский переключателем.
Чистая статика в `public/`, без сборки и зависимостей.

## Структура

```
README.md
public/                  всё, что уезжает на хостинг
  index.html             главная (SV + EN)
  legal.html             юридическая страница (SV + EN)
  styles.css             палитра, типографика, сетки, адаптив, печать
  script.js              язык, шапка, мобильное меню, reveal, AI-ассистент
  _headers               CSP, HSTS, кеш — Cloudflare Pages читает сам
  assets/
    boot.js              язык до отрисовки (отдельный файл из-за CSP)
    fonts/               локальные woff2 + fonts.css + лицензии OFL
```

## Локально

```bash
cd public && python3 -m http.server 8000
```

Запускать именно из `public/`, иначе относительные пути не найдут `assets/`.

## Деплой — Cloudflare Pages

| Настройка | Значение |
|-----------|----------|
| Production branch | `main` |
| Build command | *пусто* |
| Build output directory | `public` |
| Root directory | `/` |

Сборки нет, Pages просто публикует папку. Если увижу
`Error: Output directory "public" not found` — значит в дашборде сбилась
output directory.

`Retry deployment` пересобирает **тот же коммит**. Чтобы собрать свежий, нужен
новый пуш или deploy hook.

## Двуязычность

- Каждый текст продублирован: `<span lang="sv">…</span><span lang="en">…</span>`
- CSS показывает только активный язык
- **Шведский по умолчанию.** Язык браузера не угадывается: клиенты шведские,
  английский — осознанный выбор через переключатель
- Выбор пишется в `localStorage` **только по клику**, не при загрузке
- Без JavaScript работает и показывает шведскую версию

Правлю текст — правлю обе версии рядом.

**Стиль:** от первого лица, живым языком, без длинных тире. Исключение —
диапазон статей `GDPR art. 15–21`.

### Шрифты локальные

Google Fonts CDN не используется: загрузка шрифта с серверов Google отправляет
IP посетителя третьей стороне без согласия (LG München, 2022). Для сайта,
который продаётся адвокатским и аудиторским бюро, это лишний риск.

Оба шрифта под SIL OFL 1.1, лицензия обязана лежать рядом с файлами —
`assets/fonts/OFL-*.txt`. На диске ~184 КБ, но благодаря `unicode-range`
страница качает ~80 КБ: `latin-ext` не трогается, пока не встретится символ.

## Заголовки и CSP

`public/_headers`. Строгий `Content-Security-Policy`: `default-src 'none'`,
обратно разрешено только своё же, плюс домены ассистента.

Инлайновые скрипты запрещены — поэтому скрипт языка вынесен в
`assets/boot.js`. Добавлю инлайновый `<script>` или `style="..."` — молча не
сработает.

HSTS: `max-age=31536000; includeSubDomains`. `preload` не ставлю — попасть в
список легко, выйти месяцы.

`Permissions-Policy` разрешает `microphone=(self)` — без этого голосовой
ассистент не работает.

## AI-ассистент

ElevenLabs, `agent_8601kznz8bpmf1rv2sw0ngz89rj2`.

**Грузится только по клику.** Виджет не лежит на странице: кнопка
«Starta assistenten» подтягивает скрипт и монтирует `<elevenlabs-convai>`. До
нажатия сайт делает ноль внешних запросов.

Это юридическая конструкция, а не удобство: нажатие и есть согласие
(GDPR ст. 6.1 a), поэтому раскрытие стоит над кнопкой. Если скрипт не
загрузился — сообщение об ошибке на нужном языке и почта запасным вариантом.

### Открытые пункты

1. **Календарь.** У агента `tools: []` — записать встречу в Google Calendar он
   не может. Пока календарь не подключён, говорит «отмечу время, подтвержу по
   почте». Поэтому кнопки cal.com на месте. Подключу календарь — убрать cal.com.
2. **Prompt injection** — включить в дашборде: Guardrails → Prompt injection.
   Через API не применяется.
3. **Домены в CSP** взяты из документации. Если виджет не появится, консоль
   назовёт заблокированный хост, добавить в `_headers`. Первое, что проверить —
   `require_origin_header`.
4. `daily_limit` — 100000 в сутки. Origin-ограничение прикрывает, но можно
   уменьшить.
